ZERO-SHOT CASES

This folder contains a 20-second file for each of four cases: 5 CSVs total. Each has 60 Hz samples at 1000 rpm (nominal shaft frequency 16.6667 Hz).

Cases: 
(1) 4 tubes, 0.95/0.95/0.95/1.00 mL; 
(2) 2 tubes, 1.00/0.90 mL; 
(3) balanced 2 x 1.00 mL; 
(4) balanced 4 x 1.00 mL. 

Metadata is in zero_shot_metadata.csv. Rotor positions use the centrifuge's 24-position clockwise convention.

The app uses only the first 2 seconds of each uploaded file.
